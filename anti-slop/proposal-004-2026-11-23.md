# antislop design proposal 004, 23 November 2026

Mode: **after** (global preference). Scope: the popup, the side panel and the archive page at version 1.8.1, commit `0bbd029`. Direction: [DESIGN.md](../DESIGN.md), dial ENERGY 1 / RHYTHM 1 / MOTION 1.

You asked for four things:
- export choices in the popup, laid out like the *Teams Chat Exporter* reference, so you don't have to open the archive page to pick a format;
- the archive page as one page instead of tabs, with only what is needed;
- an answer on whether Troubleshooting and Overview are still needed;
- HTML page, Markdown and CSV removed from the formats.

Nothing below has been changed yet. Pick the numbers to build.

## Your question: Knowledge system or Full backup

Both make the same file: the **Knowledge package**, a ZIP with a transcript, the records and the pictures. They differ in one checkbox:

| | Knowledge system | Full backup |
| --- | --- | --- |
| System messages ("Alice added Bob to the chat") | left out | kept |
| Everything else (pictures, attachments, replies, reactions, edit history) | kept | kept |

A knowledge tool doesn't need the join and rename lines; a backup should hold everything. Because the difference is one checkbox, number 3 removes both buttons.

## Proposals

### HIGH

**1. Capture and save a file from the popup.**

The popup becomes one flow, in the reference's order: which messages, which format, what to include, one button. It replaces today's four capture tiles and the period row.

- **Messages.** One grid of buttons, two per row, like the reference's date range:
  - *New messages* · *Last 24 hours* · *Last 7 days* · *Last 30 days* · *Full history* · *From a date…* · *On screen*.
  - One click picks the period. Today *A period* needs a second click in a row that appears under the tiles.
  - The one-sentence hint stays under the grid.
- **Save a file.** A checkbox, remembered. When it is off, the format and Include are hidden and the popup only captures, as today.
- **Format.** Four tiles in one row: *PDF* · *Text* · *JSON* · *ZIP package*. Under the row, one line says what the chosen one makes, for example *Opens the print dialog to save a PDF*.
- **Include.** A two-column checklist: Pictures, File attachments, Reply context, Reactions, System messages, Edit history. Choices the format fixes stay ticked and disabled, with the note that says why, as on the Export page today.
- **The button** names both steps: *Capture the last 7 days and save a PDF*. With the checkbox off: *Capture the last 7 days*.
  - It sits in a bar at the bottom of the popup that stays in view. By my estimate (not measured yet) the choices are about 70 px taller than a 380 × 600 popup, and the button is the focal point.
- **What the file covers:**
  - for a period, that period;
  - for *New messages* and *Full history*, everything archived of the chat;
  - for *On screen*, the messages on screen.
- **Without capturing.** A small link under the button, *Save a file from the archive only*, saves what is already archived for this chat without scrolling Teams. It is shown only for a chat that has archived messages.
- **After the run**, the result line names the file (*Saved Design-review-2026-11-23T09-30-00.pdf*) and keeps **Open this chat in the archive**.
- **Where the file is written.** In a hidden page of the extension, not in the popup itself, so that closing the popup doesn't cancel it. PDF still opens a tab with the print dialog. The export code itself doesn't change.

**2. Four formats: PDF, Text, JSON, ZIP package.**

- HTML page, Markdown and CSV are removed from the choices. The *Packaging* row goes too, since only the HTML page had one.
- **The default** for a first use is **PDF**. JSON is never the default.
  - A choice saved earlier as HTML page, Markdown or CSV becomes PDF.
- **What stays in the code.** PDF prints the HTML page and the ZIP package holds a Markdown transcript, so those two writers stay. The CSV writer is deleted.
- Files exported before still import: JSON and the package don't change.

### MEDIUM

**3. No presets.** *Start from: Knowledge system / Full backup* is removed.
- The ZIP package with Include reaches either one.
- The full backup is **Back up now…** (number 4), which already writes the package with everything.

**4. One archive page, without tabs.** The tab bar (Overview, Conversations, Export, Settings) goes. The page holds, from the top:
1. **Conversations**: the search and the list, the page's focal point. Clicking a chat opens its messages, with **Back**, as now.
2. **Backup and import**: the last backup, the totals (conversations, messages, saved images, complete histories), **Back up now…** and **Import archive…**.
3. **Settings**: General, with **Advanced** collapsed.
4. **About**, as one line at the end.

The Export tab goes:
- Saving a file for **one chat** moves to that chat's page, using the same block as the popup (format, Include, button).
- Saving **all chats** is **Back up now…**.
- Saving **several chosen chats into one file** is no longer offered. Say *keep* if you use it, and it stays as a part of the chat list: tick chats, then **Save a file…**.

**5. Overview goes.** Its parts move or go:

| Part | Where |
| --- | --- |
| Backup line, **Back up now…**, totals | Backup and import (4) |
| Latest activity | Removed: it is the chat list sorted by recent, which the list already offers |
| Recent runs | Removed. Each chat still shows its last update, and the popup shows the last run's result. The list of every run, with status and duration, is lost. Say *keep* if you want it under Advanced. |

**6. Troubleshooting stays, out of the way.**

My advice is to keep it. The fixes in 1.8.1 came from the two reports it made: the chat id in the header, and the senders of quoted replies. Teams Web changes without notice, and without a report the next breakage has to be guessed at.

What changes:
- it moves inside **Advanced** on the archive page;
- the popup's link in **Options** goes;
- the popup's *Nothing found on this page?* hint stays, because it only shows when the extension finds nothing.

Say *remove* to delete it entirely. The selector overrides would then stay in Advanced, but nobody could see what to put in them.

### LOW

**7. The popup's Options** keeps only *Re-read archived parts*.

**8. Settings keep their fields.**
- **General**: scrolling speed, save images, pause while hidden, your display name, date order, run length, update overlap.
- **Advanced**: the scroll tuning and the selector overrides, collapsed.
- **Save images** is not the same as Include → *Pictures*. Save images decides whether a capture keeps the pictures at all; Include decides whether a file contains them. Both are needed, and each one's label is reworded to say which it is.

## DESIGN.md changes

- **Focal point.**
  - Popup: the button in the bar at the bottom, which names what it captures and what it saves.
  - Archive page: the chat list.
  - Overview and Export are removed from the table.
- **Shape and space.**
  - The messages grid is drawn as segments (a heavier bottom edge when chosen).
  - Formats are tiles with a name only, and the line about the chosen one goes under the row.
- **Icons.** Unchanged: none on sections, formats or options (see below).

## Not taken from the reference (R-37)

| Pattern in the reference | Why | Default |
| --- | --- | --- |
| An icon on each section heading, format and option | R-04; DESIGN.md icons (only where a label won't fit) | Drop |
| Uppercase, letter-spaced section labels | R-06; DESIGN.md typography | Drop: sentence case |
| Each section in its own bordered box | DESIGN.md shape | Drop: space and a heading |
| JSON chosen first | Your rule: JSON is never the default | PDF first |
| *Avatars* in Include | The extension doesn't save other people's profile pictures | Not offered |

Say *keep* for any of these to have it anyway.
