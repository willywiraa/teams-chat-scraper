# antislop audit 001, 22 November 2026

Mode: **after** (session override). Scope: the popup, the side panel (the same page as the popup) and the archive page (Overview, Conversations, a conversation, Export, Settings), at version 1.6.0, commit `a289f69`. Direction: [DESIGN.md](../DESIGN.md), dial ENERGY 1 / RHYTHM 1 / MOTION 1.

Nothing has been changed. Pick the numbers to fix; numbers not picked are left as they are.

Priority follows the rule's tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks and craftsmanship = LOW. The Liveliness checks have no tier of their own and are rated MEDIUM here.

## How it was checked

- The pages were built from the current source and opened in a browser against a seeded archive (a 451-message group chat *Design review* with one picture, and a 1:1 chat *Alice Andersen*), with a stub for the extension APIs. Dark theme (Windows setting), then the 375 px and 380 px widths.
- Sizes, colours and contrast were read from the rendered page (`getBoundingClientRect`, `getComputedStyle`) and computed with the WCAG formula. No number below is estimated.
- The source was read for every state the browser run could not reach (an empty archive, an export with nothing selected).

## Findings

### HIGH

**1. R-27: "Show earlier messages" has no loading state, and a second click adds the same messages again.**
Clicking it twice before the first page arrives drew 600 messages, of which 400 were distinct: 200 duplicates in the list. The button stays enabled while it loads, and `guarded()` does not stop a second run.
Where: `src/ui/archive/conversation-view.ts:85` (`loadEarlier`), `src/ui/archive/context.ts:24` (`guarded`).
Fix: disable the button and label it "Loading earlier messages…" while it runs; make `guarded()` ignore a click while the same action is still running, which covers every async button that uses it (Back up now, Images, row actions).

**2. R-27: no loading state on the archive page or in the popup.**
Every view is `hidden` until its data has been read, so while the archive is read the page shows only the header and the navigation. In the preview that blank page lasted 2 to 5 seconds. The popup's main area is empty until the tab answers.
Where: `src/ui/archive.html` (all `section.view` start `hidden`), `src/ui/archive.ts` (`show`), `src/ui/popup.html:20`.
Fix: show the view's heading at once with a muted "Reading the archive…" line and `aria-busy="true"` on the view until the data is drawn; in the popup, "Checking this tab…" until the first status.

**3. R-27: empty states that do not name the next action, and one that is missing.**
DESIGN.md asks every empty state to name the next action.
- Overview, Recent runs: "No runs yet." Proposed: "No runs yet. Open a chat in Teams Web and click the toolbar button."
- Conversations, search: "No conversation matches the search." Proposed: the same sentence plus a "Clear the search" button.
- A conversation: "No messages are archived for this chat." Proposed: add "Open it in Teams Web and click Start to archive it."
- Export with an empty archive: an empty list, "0 of 0 selected", and a disabled Export with no reason. With every chat deselected, Export is disabled with no reason either.

Proposed: "Nothing archived yet, so there is nothing to export." for the empty archive, and "Select at least one conversation." beside the disabled Export.
Where: `src/ui/archive.html:64, 108, 136`; `src/ui/export-panel.ts:134, 223`.

**4. R-25 (non-text contrast, antislop-human, WCAG 1.4.11): control edges are too faint to find.**
Buttons, selects, the search field and checkboxes are outlined with `--border`, which is meant for structure:

| Pair | Light | Dark | Needed |
| --- | --- | --- | --- |
| Control border on card | 1.36:1 | 1.34:1 | 3:1 |
| Control border on page background | 1.25:1 | 1.53:1 | 3:1 |
| Current navigation entry background on header | 1.19:1 | 1.20:1 | 3:1, or a second signal (see 7) |

Fix: a separate `--control-border` for controls only, keeping `--border` for card edges and table rules. These values were computed to pass:
- light `#86868f`: 3.61 on card, 3.31 on background;
- dark `#7a7a86`: 3.55 on card, 4.05 on background.

Add both to DESIGN.md's palette and to the contrast test.
Where: `src/ui/ui.css:409` (buttons and selects), `:521` (search field), `:703`; `tests/unit/logo.test.ts`.

**5. R-25: placeholder text is below 4.5:1.**
The placeholders use the browser's default grey `#757575`:
- 3.26:1 in the dark search field;
- 4.23:1 (light) and 3.73:1 (dark) in the Advanced settings text area, which sits on the page background.

Fix: `::placeholder { color: var(--muted); opacity: 1; }`. The muted text colour measures:
- on card: 5.93 light, 6.02 dark;
- on background: 5.45 light, 6.87 dark.

Where: `src/ui/archive.html:82, 200`; `src/ui/ui.css`.

**6. R-03: controls are smaller than the 44 px tap target.**
Measured heights:

| Control | Size (px) |
| --- | --- |
| Buttons | 29 |
| Selects | 30 |
| Search field | 27 |
| Navigation links | 25 |
| Popup header icon buttons | 27 × 27 |
| Popup "More" | 17 |
| The image count link in the conversation list | 15 × 25 |

Everything except that 15 px link is above WCAG 2.2's 24 px minimum, but R-03 asks for 44 px.
Fix:
- With a touch screen (`pointer: coarse`): a minimum height of 44 px for buttons, selects, inputs, navigation links and summaries.
- With a mouse: a minimum of 32 px, so the pages stay compact.
- Widen the image count link with padding.

If 44 px should apply everywhere, including the 380 px popup with a mouse, say so.
Where: `src/ui/ui.css:404` and the navigation and icon-button rules.

**7. R-39: controls do not all show that they can be used.**
- Checkboxes and the labels that wrap them show the arrow cursor (Export's conversation list and content options, the popup's "Re-read archived parts").
- Disabled controls use `cursor: default` rather than `not-allowed`.
- No control has a pressed (`:active`) state.
- Hover, and the current navigation entry, are shown by colour alone.

Fix:
- `cursor: pointer` on `input[type=checkbox]`, `label.check` and `label[for]`, and `not-allowed` on disabled controls;
- a pressed state on buttons that changes more than colour (the selected background and a 2 px bottom edge);
- a 2 px accent underline on the current navigation entry.

Where: `src/ui/ui.css:404-430, 188-204`.

**8. R-39: four fields have no visible label.**
- The Type and Sort selects on Conversations have visually hidden labels, so "Recently archived" does not say it is a sort order.
- The search field is named only by its icon and placeholder.
- The popup's "Capture from this date" field has only an `aria-label`.

Fix: small visible labels above the toolbar fields ("Search", "Type", "Sort by"), wrapping on narrow widths, and a visible "From" label for the popup date.
Where: `src/ui/archive.html:80-87`, `src/ui/popup.html:61`.

**9. R-40: pictures are drawn without a width and height.**
The pictures in a conversation and the tiles of the image dialog are `<img loading="lazy">` with no dimensions, so the list moves as each one loads. The stored image record already has `width` and `height`, which are null only when they were not known.
Fix: set `width` and `height` from the record when they are known; otherwise reserve a fixed box in CSS (`aspect-ratio: 4 / 3`, `object-fit: contain`).
Where: `src/ui/archive/conversation-view.ts:166`, `src/ui/archive/conversations.ts:167`.

### MEDIUM

**10. Liveliness, one accent: Settings shows three primary buttons at once.**
Settings is one scrolling page, and Save settings, Back up now… and Run diagnostics all use the accent. DESIGN.md keeps the accent for the one primary button of a view.
Fix: keep Save settings as the primary button; make Back up now… and Run diagnostics normal buttons.
Where: `src/ui/archive.html:208, 220, 235`.

**11. Liveliness, focal point: Overview does not lead with whether the archive is safe.**
DESIGN.md names the totals and Back up now as Overview's focal point. In practice, Back up now is a link inside the storage sentence, the five totals are equal boxes, and nothing says when the last backup was made.
Fix: a backup line under the totals ("Last backup: never" or its date) with Back up now as the view's primary button. This needs the time of the last backup stored when a Full backup export finishes, which is a small addition to the settings record. Without that, the button alone can still move out of the sentence.
Where: `src/ui/archive.html:28-37`, `src/ui/archive.ts`.

### LOW

**12. C-4: "1 messages" and "1 saved images".**
The Export list shows "Alice Andersen · 1 messages" (seen in the browser). The merge dialog and the image count's accessible name use the same unconditional plural.
Fix: use the singular for one, as the conversation view already does.
Where: `src/ui/export-panel.ts:140`, `src/ui/archive/conversations.ts:78, 208`.

**13. R-11: the image dialog's corner radius is 10 px.**
DESIGN.md sets 8 px for cards and other surfaces. The 10 px of the run-phase badge is the one pill DESIGN.md allows and is fine.
Fix: `var(--radius-m)`.
Where: `src/ui/ui.css:780`.

**14. C-1: unused `label.button` styles.**
No element uses the class any more, since Import became a real button.
Fix: remove it from the two rules.
Where: `src/ui/ui.css:405, 418`.

**15. R-20: the name differs between the pages.**
The popup is titled "Teams Chat Extractor" and the archive page "Teams Chat Archive". This waits on decision 1 (the name) in docs/IMPROVEMENT_PLAN.md and is listed only so it is not forgotten.
